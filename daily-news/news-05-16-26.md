## AI News Digest

### AI Models and Development
**Zyphra Releases ZAYA1-8B-Diffusion-Preview: First MoE Diffusion Model from Autoregressive LLM**
Zyphra has unveiled ZAYA1-8B-Diffusion-Preview, a pioneering Mixture-of-Experts (MoE) diffusion model converted from an autoregressive LLM. This innovation achieves up to a 7.7x inference speedup by shifting decoding from memory-bandwidth bound to compute-bound, without systematic loss in evaluation performance. This is significant as it addresses a key bottleneck in modern GPU performance scaling. (Source: [MarkTechPost](https://www.marktechpost.com/2026/05/15/zyphra-releases-zaya1-8b-diffusion-preview-the-first-moe-diffusion-model-converted-from-an-autoregressive-llm-with-up-to-7-7x-speedup/))

**Nous Research Releases Token Superposition Training to Speed Up LLM Pre-Training**
Nous Research introduced Token Superposition Training (TST), a two-phase pre-training method that can accelerate wall-clock training time by up to 2.5x for LLMs ranging from 270M to 10B parameters. TST averages contiguous token embeddings during Phase 1 and then reverts to standard next-token prediction, without altering model architecture or inference behavior, offering a significant efficiency boost for LLM development. (Source: [MarkTechPost](https://www.marktechpost.com/2026/05/13/nous-research-releases-token-superposition-training-to-speed-up-llm-pre-training-by-up-to-2-5x-across-270m-to-10b-parameter-models/))

**IBM Releases Granite Embedding Multilingual R2**
IBM has released Granite Embedding Multilingual R2, an open Apache 2.0 licensed multilingual embedding model with a 32K context window. This model is highlighted for achieving the best sub-100M retrieval quality, making it a valuable resource for developers working with multilingual data and retrieval-augmented generation systems. (Source: [Hugging Face - Blog](https://huggingface.co/blog/ibm-granite/granite-embedding-multilingual-r2))

**Supertone Releases Supertonic v3 On-Device Text-to-Speech Model**
Seoul-based speech AI company Supertone has launched Supertonic v3, its third-generation on-device Text-to-Speech (TTS) engine. This version supports 31 languages, features improved reading stability, and includes expression tags, all while maintaining the same inference contract for existing integrations. This advancement makes high-quality, multilingual TTS more accessible for on-device applications. (Source: [MarkTechPost](https://www.marktechpost.com/2026/05/15/supertone-releases-supertonic-v3-on-device-text-to-speech-model-with-31-language-support-fewer-reading-failures-and-expression-tags/))
