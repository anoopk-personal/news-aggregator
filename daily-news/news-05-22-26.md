**Microsoft Releases Fara1.5 Browser Agents**

Cohere has released Command A+, an open-source 218B Sparse Mixture-of-Experts model optimized for agentic workflows. This model consolidates four prior Command A variants, supports 48 languages, and can run on as few as two H100 GPUs. (Source: [MarkTechPost](https://www.marktechpost.com/2026/05/21/cohere-releases-command-a-a-218b-sparse-moe-model-for-agentic-workflows-that-runs-on-as-few-as-two-h100-gpus/))

(Source: [MarkTechPost](https://www.marktechpost.com/2026/05/21/one-model-three-modalities-bytedance-releases-lance-for-image-and-video-understanding-generation-and-editing/))

**NVIDIA AI Releases Nemotron-Labs-Diffusion Language Model**
NVIDIA researchers have released Nemotron-Labs-Diffusion, a family of language models that unifies three decoding modes: autoregressive, diffusion-based parallel, and self-speculation.
