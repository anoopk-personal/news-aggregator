**Liquid AI Releases On-Device MoE Model LFM2.5-8B-A1B**
Liquid AI has introduced LFM2.5-8B-A1B, an on-device Mixture-of-Experts (MoE) model with 8.3 billion total parameters and 1.5 billion active parameters. (Source: [MarkTechPost](https://www.marktechpost.com/2026/05/28/liquid-ai-releases-lfm2-5-8b-a1b-an-on-device-moe-model-with-8-3b-total-and-1-5b-active-parameters/))

**Hexo Labs Open-Sources SIA: A Self-Improving Agent**
Hexo Labs has open-sourced SIA (Self-Improving Agent), a loop that updates both the agent's harness and model weights. SIA uses a Feedback-Agent to read run trajectories and either rewrites the scaffold or triggers a LoRA weight update on gpt-oss-120b. This approach has shown improved performance on benchmarks like LawBench and TriMul GPU kernels.
(Source: [MarkTechPost](https://www.marktechpost.com/2026/05/29/hexo-labs-open-sources-sia-a-self-improving-agent-that-updates-both-the-harness-and-the-model-weights/))

**NVIDIA Releases Polar for GRPO Training Across Code Models**
NVIDIA researchers have introduced Polar, a token-faithful rollout framework for training language agents using reinforcement learning (GRPO). Polar works by placing a model API proxy between the agent harness and inference server, capturing token-level interactions to reconstruct trainer-ready trajectories. It improved SWE-Bench Verified pass@1 by 22.6 points with Qwen3.5-4B under the Codex harness.
(Source: [MarkTechPost](https://www.marktechpost.com/2026/05/27/nvidia-releases-polar-a-token-faithful-rollout-framework-for-grpo-training-across-codex-claude-code-and-qwen-code/))

**Sakana AI Proposes DiffusionBlocks for Independent Denoising Modules**
Sakana AI has proposed DiffusionBlocks, a block-wise training framework that converts residual networks into independently trainable denoising modules. This is achieved by interpreting layer updates as reverse diffusion denoising steps, potentially simplifying the training of complex neural networks.
(Source: [MarkTechPost](https://www.marktechpost.com/2026/05/27/sakana-ai-proposes-diffusionblocks-a-block-wise-training-framework-that-converts-residual-networks-into-independently-trainable-denoising-modules/))

**Perplexity AI Open-Sources Faster Unigram Tokenizer**
Perplexity AI has open-sourced a rewritten Unigram tokenizer that significantly reduces reranker latency and cuts production CPU utilization by 5-6x. This improvement can lead to more efficient and faster AI applications.
(Source: [MarkTechPost](https://www.marktechpost.com/2026/05/28/perplexity-ai-open-sources-unigram-tokenizer-that-achieves-5x-lower-p50-latency-than-hugging-face-tokenizers-crate/))

**EAGLE 3.1 Fixes Attention Drift in LLM Inference**
The EAGLE team, vLLM, and TorchSpec have jointly released EAGLE 3.1, a speculative decoding algorithm designed to fix instability caused by attention drift in large language model (LLM) inference, improving the reliability of LLM outputs in production.
