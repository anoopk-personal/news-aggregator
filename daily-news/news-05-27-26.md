**MEMO: A Modular Framework for Training a Dedicated Memory Model on New Knowledge Without Modifying LLM Parameters**
Researchers from NUS, MIT, and A*STAR have proposed MEMO, a modular framework that allows LLMs to incorporate new knowledge by training a separate memory model without altering the core LLM parameters. This approach offers a more efficient and flexible way to update LLMs with new information. (Source: [MarkTechPost](https://www.marktechpost.com/2026/05/26/memo-a-modular-framework-for-training-a-dedicated-memory-model-on-new-knowledge-without-modifying-llm-parameters/))

**Together AI Open-Sources OSCAR: An Attention-Aware 2-Bit KV Cache Quantization System for Long-Context LLM Serving**
Together AI has open-sourced OSCAR (Offline Spectral Covariance-Aware Rotation), an INT2 KV cache quantization method that significantly reduces memory usage and improves decode speed for long-context LLM serving. OSCAR achieves approximately 8x KV memory reduction and up to 3x decode speedup at 100K context length, addressing a critical bottleneck in LLM performance. (Source: [MarkTechPost](https://www.marktechpost.com/2026/05/25/together-ai-open-sources-oscar-an-attention-aware-2-bit-kv-cache-quantization-system-for-long-context-llm-serving/))
